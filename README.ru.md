# AutoGameSoftwareSync (AGSS)

[English](README.md) | [Français](README.fr.md) | **Русский** | [Español](README.es.md) | [中文](README.zh.md)

Ваши сохранения и настройки игр и программ — с одного ПК на другой (стационарный, портативный вроде Legion Go S...) через любую общую папку: Google Drive, Dropbox, NAS и т. д. Бесплатно для личного использования.

[**Скачать последнюю версию**](https://github.com/Epikou/AutoGameSoftwareSync/releases/latest) · [Поддержать проект на Ko-fi](https://ko-fi.com/autogamesoftwaresave)

## Что делает программа

- Сохраняет данные игры при её закрытии и восстанавливает самую свежую версию на другом ПК.
- Не теряет данные: каждое сохранение — отдельная уникальная папка, старые версии всегда хранятся, а перед любым восстановлением создаётся резервная копия.
- Находит ваши игры (Steam, Epic, GOG) и знает тысячи расположений сохранений. Есть и ручное добавление.
- Работает тихо в области уведомлений и может запускаться вместе с Windows (в том числе в полноэкранном режиме Xbox на портативных консолях).
- Полное управление геймпадом (DualSense, контроллеры Xbox). Языки: English, Français, Русский, Español, 中文.

## Как пользоваться

1. Скачайте `AutoGameSoftwareSync.exe` на странице [Releases](https://github.com/Epikou/AutoGameSoftwareSync/releases) и поместите его в постоянную папку (например, `C:\Tools\AutoGameSoftwareSync`).
2. Запустите его. Короткий обучающий тур объяснит каждый шаг: выбор общей папки, добавление первой игры, настройки.
3. Повторите на другом ПК с **той же общей папкой** и нажмите **Присоединиться** у существующей игры.

Если общая папка — Google Drive, включите режим *«Зеркальное отображение файлов»* (или сделайте папку *доступной офлайн*), иначе чтение может быть очень медленным.

## Linux / SteamOS

Доступна и сборка для Linux (x86_64): SteamOS (Steam Deck, Legion Go S...), Bazzite и Ubuntu. Скачайте `AutoGameSoftwareSync-v1.3.3-linux-x86_64.tar.gz` со страницы [Releases](https://github.com/Epikou/AutoGameSoftwareSync/releases/latest), распакуйте архив и запустите `install-linux.sh` (права администратора не нужны). Сохранения полностью совместимы с версией для Windows через ту же общую папку. Руководство по установке (на французском): [docs/LINUX.md](docs/LINUX.md).

## Предупреждение Windows SmartScreen

Программа пока не имеет цифровой подписи. При первом запуске Windows может показать «Windows защитила ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом случае**. Это предупреждение исчезает по мере роста числа пользователей.

## Безопасность

Перед первым использованием сделайте ручную копию ваших сохранений. Программа предоставляется «как есть», без гарантий (см. [TERMS.md](TERMS.md)).

## Известное ограничение

Программа не может восстановить сохранение *до* запуска игры, если игра запущена вне интегрированного лаунчера. Для этого планируется расширение для Playnite.
